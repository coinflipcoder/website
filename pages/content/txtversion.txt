Here are some of the things I have worked on.

~[ Website ]~
This website is built using Flask and deployed via Gunicorn. It uses Jinja to serve dynamic HTML files. Look ma, no Javascript!

~[ Velocity Plugin ]~
A Minecraft Velocity plugin tailored to my network. It will not work on your server, but be my guest to do some tactical communism in my code.
Languages: java
 - Github > https://github.com/coinflipcoder/CustomPlugin

~[ No Join Leave Message ]~
Quick and dirty Minecraft Fabric mod that disabled joining and leaving messages.
Languages: java
 - Github > https://github.com/coinflipcoder/No-Join-Leave-Message
 - Modrinth > https://modrinth.com/mod/no-join-leave-messages

~[ Better Beacon Range ]~
Minecraft Fabric mod that makes the beacon effect range configurable.
Languages: java
 - Github > https://github.com/coinflipcoder/Better-Beacon-Range
 - Modrinth > https://modrinth.com/mod/better-beacon-range-was-taken

~[ Neon ]~
A Minecraft Fabric hacked client that I made to play on LiveOverflow's server. A lot of this code is 'borrowed' from other clients as this was my learning project.
Languages: java
 - Github > https://github.com/coinflipcoder/neon

~[ Harder Dragon ]~
Small Minecraft Paper plugin that makes the dragon fight incresingly more difficult.
Languages: java
 - Github > https://github.com/coinflipcoder/Harder-Dragon
 - Modrinth > https://modrinth.com/plugin/harder-dragon

~[ Bad Discord Bot ]~
A very bad and probably non functional Discord bot written in Python. The Framework I made is really nice :)
